# 기획 문서 (1장) — 용돈박스+결합상품 경쟁 분석 대시보드

## 도메인 연결성 — 한 문장

> 내 "1688 소싱·리패키징 예비 창업가"로서의 이 불편함을 풀기 위해 만들었다: 용돈박스에 실제로 어떤 상품이 결합되어 팔리는지 감으로만 판단해야 했던 문제를, CSV 업로드 한 번으로 가격대·구성 공통점을 자동 분석해주는 대시보드로 해결한다.

## 서비스 개요

옥(玉) 지압봉을 1688에서 소싱해 용돈박스와 묶어 "효도 선물"로 재판매하는 사업을 구상하던 중, 결합 대상을 지압봉으로 확정 짓기 전에 **시장에서 용돈박스가 실제로 어떤 상품과 결합되어 팔리는지**부터 데이터로 확인하기 위해 만든 1인용 조사·분석 도구다. 직접 조사한 경쟁 상품 데이터를 CSV/엑셀로 업로드하면, 가격대 분포와 구성 공통점(용돈박스 형태 × 결합상품 유형)을 자동으로 뽑아 상품 비교 표까지 제공한다.

## 타겟 사용자

이 서비스 자체의 사용자는 **본인(예비 창업가) 1인**이다. 다만 이 조사·분석 결과가 최종적으로 겨냥하는 시장은 구매자와 사용자가 분리된 구조다.
- 구매자(지갑을 여는 사람): 부모님께 효도하고 싶은 20~30대 자녀
- 사용자(실제로 쓰는 사람): 50~60대 부모님

## 해결하려는 문제

- 옥 지압봉은 검색량이 적고 "괄사"라는 더 넓은 카테고리에 묻혀, 단독으로는 경쟁 구도를 파악할 수 없다.
- 용돈박스에 결합되는 상품이 지압봉뿐 아니라 화장품·건강식품·조화 장식 등 다양한데, 어떤 유형이 실제로 흔하고 어떤 가격대에서 팔리는지 감으로는 판단하기 어렵다.
- 이 도구는 "상품을 출시하는 것"이 아니라 **"경쟁 구도를 숫자와 표로 파악하는 것"** 이 목적이다 — 실제 조사(20건) 결과, 지압봉 결합 상품은 0건으로 확인됐고, "조화 장식" 계열이 35~40%로 압도적임을 데이터로 확인했다 (자세한 내용: [docs/CONCLUSION.md](./CONCLUSION.md)).

## 핵심 가치 (30초 피치용)

> "부모님 선물, 어떤 걸 넣어야 팔릴지 감으로 정하지 않는다." 조사한 경쟁 상품 CSV를 올리면 30초 안에 가격대·자주 팔리는 구성·빈 자리(아직 아무도 안 쓴 결합상품)를 보여주는 1인용 대시보드다.
