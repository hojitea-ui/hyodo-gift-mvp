# PRD — 용돈박스+결합상품 경쟁 상품 분석 대시보드

- 이 문서가 다루는 범위: **사업 전체가 아니라, 그 전 단계인 "경쟁 상품 분석 MVP"**

## 1. 배경

### 1.1 사업 아이템
- 1688에서 옥(玉) 지압봉 원물을 소싱해, **용돈박스**(부모님께 용돈을 담아 드리는 케이스/봉투형 상품)와 묶어 "효도 선물" 컨셉으로 재판매하는 것을 사업 아이디어로 구상 중이다.
- 다만 우리 상품의 결합 대상을 지압봉으로 확정 짓기 전에, **시장에서 용돈박스가 실제로 어떤 상품들과 결합되어 팔리는지**부터 폭넓게 파악하려고 한다.
- **구매자와 사용자가 분리된 시장**이라는 점이 핵심 특징이다.
  - 구매자(지갑을 여는 사람): 부모님께 효도하고 싶은 20~30대 자녀
  - 사용자(실제로 쓰는 사람): 50~60대 부모님

### 1.2 지금 이 MVP가 필요한 이유
- 옥 지압봉만으로는 시장에서 독립된 카테고리로 검색·비교되지 않는다 — "괄사" 안에 묻히거나 단품으로만 팔리는 경우가 많다.
- 반면 "용돈박스+무언가 결합된 선물 세트"는 이미 시장에 다양하게 존재한다 (지압봉뿐 아니라 화장품, 건강식품, 안마용품 등도 결합 후보가 될 수 있다). 어떤 결합상품이 실제로 흔하고, 어떤 가격대에서 팔리는지 감으로는 판단하기 어렵다.
- 지압봉으로 결합 대상을 미리 좁히지 않고 **"용돈박스+결합상품" 전체**를 조사해야, 아래를 데이터로 판단할 수 있다.
  - 용돈박스에 실제로 자주 결합되는 상품 유형이 무엇인지 (지압봉이 그중 흔한 편인지, 아닌지)
  - 결합상품 유형별로 가격대가 어떻게 다른지
  - 용돈박스 형태(봉투형/케이스형/카드형 등)와 결합상품 유형의 조합 패턴
  - 우리 상품(지압봉 결합)을 어디에 포지셔닝해야 차별화가 되는지
- 이번 MVP의 목적은 이전과 동일하게 **"상품 출시가 아니라 경쟁 구도를 숫자와 표로 파악하는 것"**이다.

## 2. 목적 (Goal)

용돈박스+결합상품 경쟁 상품 데이터를 업로드하면, 자동으로 **가격대 분포, 결합상품 유형·구성 공통점, 상품 간 비교표**를 뽑아주는 개인용 웹 대시보드를 만든다.

### 성공 기준 (이 MVP가 "됐다"고 판단하는 기준)
1. 직접 조사한 "용돈박스+결합상품" 경쟁 상품 10~30개 정도를 CSV/엑셀로 정리해 업로드하면 에러 없이 반영된다.
2. 가격대 분포를 한눈에 볼 수 있다 (최저/최고/평균/중앙값 + 구간별 분포).
3. 어떤 결합상품 유형(지압봉/화장품/건강식품/기타 등)이 자주 등장하는지, 용돈박스 형태와 어떻게 조합되는지 빈도순으로 요약되어 보인다.
4. 상품들을 표 형태로 나란히 비교(가격순 정렬, 결합상품 유형·용돈박스 형태 필터링)할 수 있다.
5. 새로 조사한 데이터를 추가/교체해도 다시 처음부터 다 입력할 필요 없이 갱신할 수 있다.

## 4. 범위 (Scope)

### 4.1 In Scope (이번 MVP에 포함)
| # | 기능 | 설명 |
|---|------|------|
| F1 | CSV/엑셀 업로드 | 직접 조사한 "용돈박스+결합상품" 경쟁 상품 데이터를 파일로 업로드 |
| F2 | 데이터 미리보기 & 검증 | 업로드한 데이터가 제대로 인식됐는지 표로 확인, 필수 항목 누락 시 안내 |
| F3 | 가격대 분석 | 최저/최고/평균/중앙값, 가격 구간별 분포 차트 |
| F4 | 구성 공통점 분석 | 용돈박스 형태(봉투형/케이스형/카드형 등), 결합상품 유형(지압봉/화장품/건강식품/기타 등), 부가 구성품 등에서 자주 등장하는 값/조합을 빈도순으로 요약 |
| F5 | 상품 비교 테이블 | 전체 상품을 표로 나열, 가격/용돈박스 형태/결합상품 유형 기준 정렬·필터 |
| F6 | 데이터 유지 | 새로고침해도 마지막 업로드 데이터가 유지됨 (브라우저 저장) |
| F7 | 데이터 재업로드/초기화 | 새 파일로 교체하거나 전체 초기화 가능 |

### 4.2 Out of Scope (이번 MVP에서 제외 — 이후 단계)
- 실제 상품 판매 기능 (쇼핑몰, 결제, 재고, 배송)
- 회원가입/로그인/다중 사용자
- URL 자동 크롤링/스크래핑 (플랫폼별 구조 대응, 차단 우회 등 별도 과제로 분리)
- 사전예약 랜딩페이지, 마케팅 기능
- 서버/DB를 이용한 영구 저장, 여러 기기 간 동기화
- 모바일 앱
- 구성품 원가·마진 시뮬레이션 (이번 경쟁 조사 결과를 바탕으로 별도 MVP에서 다룸)
- 용돈박스 단독 상품(결합상품 없음)은 조사·분석 대상에서 제외한다 — 이번 MVP는 "용돈박스+결합상품" 세트 시장에 한정

> Out of Scope 항목들은 사업이 다음 단계로 넘어갈 때 별도 PRD로 다룬다.

## 5. 핵심 사용자 스토리

1. **데이터 입력**
   "나는 네이버/쿠팡/아이디어스 등에서 조사한 '용돈박스+결합상품' 경쟁 상품 정보를 엑셀에 정리해 뒀다. 이 파일을 업로드하면 바로 분석 화면으로 넘어가고 싶다."

2. **가격 감 잡기**
   "지금 시장에 나온 용돈박스 결합 선물 상품들의 가격이 대략 어느 구간에 몰려 있는지, 우리가 얼마로 팔면 튀지 않으면서 프리미엄으로 보일지 감을 잡고 싶다."

3. **결합상품 벤치마킹**
   "용돈박스에 실제로 자주 결합되는 상품이 지압봉인지 다른 것인지, 어떤 용돈박스 형태(봉투형/케이스형/카드형)와 자주 짝지어지는지 빠르게 파악하고 싶다."

4. **개별 비교**
   "특정 결합상품 유형(예: 지압봉)이나 가격대만 걸러서, 그 안에서 용돈박스 형태나 구성이 어떻게 다른지 표로 비교하고 싶다."

5. **데이터 갱신**
   "조사를 더 하거나 데이터를 수정한 뒤, 새 파일로 덮어써서 최신 상태로 보고 싶다."

## 6. 입력 데이터 항목 (초안)

사용자가 CSV/엑셀에 채워 넣을 컬럼. (정확한 스키마는 기술 명세서에서 확정)

- 상품명
- 판매처 (네이버/쿠팡/아이디어스/자사몰 등)
- 가격
- 용돈박스 형태 (봉투형/케이스형/카드형/기타)
- 결합상품 유형 (예: 지압봉, 화장품, 건강식품, 기타 — 자유 입력)
- 구성 내용 (예: "용돈박스 1개 + 지압봉 1개 + 파우치 + 설명서")
- 재질 (결합상품의 재질, 있는 경우 — 예: 지압봉이면 옥/합성수지/기타)
- 사이즈/길이 (선택)
- 리뷰 수 / 평점 (선택, 있으면)
- 상품 URL (참고용, 선택)
- 비고 (자유 메모)

## 7. 비기능 요구사항

- **간단함 우선**: 서버·DB·배포 인프라를 최소화해 빠르게 만들고 바로 쓸 수 있어야 한다.
- **데이터 프라이버시**: 조사한 데이터는 본인만 보는 자료이므로 외부 서버에 올라가지 않아도 된다 (로컬/브라우저 저장으로 충분).
- **재사용성**: 데이터 포맷(컬럼 구조)이 이후 실제 상품 기획 자료로도 재사용될 수 있게 정리한다.

## 8. 다음 단계와의 연결

이 MVP에서 도출한 "가격 포지셔닝 + 용돈박스·결합상품 구성 벤치마크" 결론은 이후 아래 단계의 입력값이 된다.
- **상품 구성 시뮬레이터**: 이번 조사로 파악한 결합상품 유형·용돈박스 형태와 가격 공백을 바탕으로, 우리 상품(지압봉 결합 여부 포함)의 구성·원가·판매가를 시뮬레이션하는 다음 MVP
- 패키징 컨셉 기획
- 수요 검증용 랜딩페이지 제작
- 미니 쇼핑몰 제작

이 문서는 그 이전 단계, 즉 **"의사결정을 위한 분석 도구"**에 한정한다.
